# team-collaboration

Team workflows, issue management, standup automation, and developer experience optimization

## Components

### Agents

- **dx-optimizer**: See `agents/dx-optimizer.md`

### Commands

- **/team-collaboration:issue**: See `commands/issue.md`
- **/team-collaboration:standup-notes**: See `commands/standup-notes.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
