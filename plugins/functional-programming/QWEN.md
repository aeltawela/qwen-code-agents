# functional-programming

Functional programming with Elixir, OTP patterns, Phoenix framework, and distributed systems

## Components

### Agents

- **elixir-pro**: See `agents/elixir-pro.md`
- **haskell-pro**: See `agents/haskell-pro.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
