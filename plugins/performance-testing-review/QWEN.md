# performance-testing-review

Performance analysis, test coverage review, and AI-powered code quality assessment

## Components

### Agents

- **performance-engineer**: See `agents/performance-engineer.md`
- **test-automator**: See `agents/test-automator.md`

### Commands

- **/performance-testing-review:ai-review**: See `commands/ai-review.md`
- **/performance-testing-review:multi-agent-review**: See `commands/multi-agent-review.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
