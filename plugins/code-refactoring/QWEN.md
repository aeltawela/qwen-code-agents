# code-refactoring

Code cleanup, refactoring automation, and technical debt management with context restoration

## Components

### Agents

- **code-reviewer**: See `agents/code-reviewer.md`
- **legacy-modernizer**: See `agents/legacy-modernizer.md`

### Commands

- **/code-refactoring:context-restore**: See `commands/context-restore.md`
- **/code-refactoring:refactor-clean**: See `commands/refactor-clean.md`
- **/code-refactoring:tech-debt**: See `commands/tech-debt.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
