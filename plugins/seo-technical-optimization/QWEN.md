# seo-technical-optimization

Technical SEO optimization including meta tags, keywords, structure, and featured snippets

## Components

### Agents

- **seo-keyword-strategist**: See `agents/seo-keyword-strategist.md`
- **seo-meta-optimizer**: See `agents/seo-meta-optimizer.md`
- **seo-snippet-hunter**: See `agents/seo-snippet-hunter.md`
- **seo-structure-architect**: See `agents/seo-structure-architect.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
