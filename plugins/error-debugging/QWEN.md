# error-debugging

Error analysis, trace debugging, and multi-agent problem diagnosis

## Components

### Agents

- **debugger**: See `agents/debugger.md`
- **error-detective**: See `agents/error-detective.md`

### Commands

- **/error-debugging:error-analysis**: See `commands/error-analysis.md`
- **/error-debugging:error-trace**: See `commands/error-trace.md`
- **/error-debugging:multi-agent-review**: See `commands/multi-agent-review.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
