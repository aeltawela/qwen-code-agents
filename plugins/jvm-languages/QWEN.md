# jvm-languages

JVM language development including Java, Scala, and C# with enterprise patterns and frameworks

## Components

### Agents

- **csharp-pro**: See `agents/csharp-pro.md`
- **java-pro**: See `agents/java-pro.md`
- **scala-pro**: See `agents/scala-pro.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
