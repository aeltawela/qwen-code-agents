Comprehensive UI/UX design plugin for mobile (iOS, Android, React Native) and web applications with design systems, accessibility, and modern patterns

- **accessibility-expert**: See `agents/accessibility-expert.md`
- **design-system-architect**: See `agents/design-system-architect.md`

- **/ui-design:create-component**: See `commands/create-component.md`
- **/ui-design:design-review**: See `commands/design-review.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
