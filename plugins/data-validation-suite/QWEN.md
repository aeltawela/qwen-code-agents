# data-validation-suite

Schema validation, data quality monitoring, streaming validation pipelines, and input validation for backend APIs

## Components

### Agents

- **backend-security-coder**: See `agents/backend-security-coder.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
