# database-cloud-optimization

Database query optimization, cloud cost optimization, and scalability improvements

## Components

### Agents

- **backend-architect**: See `agents/backend-architect.md`
- **cloud-architect**: See `agents/cloud-architect.md`
- **database-architect**: See `agents/database-architect.md`
- **database-optimizer**: See `agents/database-optimizer.md`

### Commands

- **/database-cloud-optimization:cost-optimize**: See `commands/cost-optimize.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
