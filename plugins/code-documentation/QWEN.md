# code-documentation

Documentation generation, code explanation, and technical writing with automated doc generation and tutorial creation

## Components

### Agents

- **code-reviewer**: See `agents/code-reviewer.md`
- **docs-architect**: See `agents/docs-architect.md`
- **tutorial-engineer**: See `agents/tutorial-engineer.md`

### Commands

- **/code-documentation:code-explain**: See `commands/code-explain.md`
- **/code-documentation:doc-generate**: See `commands/doc-generate.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
