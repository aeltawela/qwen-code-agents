# database-migrations

Database migration automation, observability, and cross-database migration strategies

## Components

### Agents

- **database-admin**: See `agents/database-admin.md`
- **database-optimizer**: See `agents/database-optimizer.md`

### Commands

- **/database-migrations:migration-observability**: See `commands/migration-observability.md`
- **/database-migrations:sql-migrations**: See `commands/sql-migrations.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
