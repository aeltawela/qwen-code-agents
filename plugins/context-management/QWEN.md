# context-management

Context persistence, restoration, and long-running conversation management

## Components

### Agents

- **context-manager**: See `agents/context-manager.md`

### Commands

- **/context-management:context-restore**: See `commands/context-restore.md`
- **/context-management:context-save**: See `commands/context-save.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
