# deployment-validation

Pre-deployment checks, configuration validation, and deployment readiness assessment

## Components

### Agents

- **cloud-architect**: See `agents/cloud-architect.md`

### Commands

- **/deployment-validation:config-validate**: See `commands/config-validate.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
