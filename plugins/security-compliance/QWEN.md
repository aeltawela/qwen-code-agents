# security-compliance

SOC2, HIPAA, and GDPR compliance validation, secrets scanning, compliance checklists, and regulatory documentation

## Components

### Agents

- **security-auditor**: See `agents/security-auditor.md`

### Commands

- **/security-compliance:compliance-check**: See `commands/compliance-check.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
