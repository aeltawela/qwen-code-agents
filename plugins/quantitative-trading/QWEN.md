# quantitative-trading

Quantitative analysis, algorithmic trading strategies, financial modeling, portfolio risk management, and backtesting

## Components

### Agents

- **quant-analyst**: See `agents/quant-analyst.md`
- **risk-manager**: See `agents/risk-manager.md`

### Skills

- **backtesting-frameworks**: See `skills/backtesting-frameworks/SKILL.md`
- **risk-metrics-calculation**: See `skills/risk-metrics-calculation/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
