# error-diagnostics

Error tracing, root cause analysis, and smart debugging for production systems

## Components

### Agents

- **debugger**: See `agents/debugger.md`
- **error-detective**: See `agents/error-detective.md`

### Commands

- **/error-diagnostics:error-analysis**: See `commands/error-analysis.md`
- **/error-diagnostics:error-trace**: See `commands/error-trace.md`
- **/error-diagnostics:smart-debug**: See `commands/smart-debug.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
