# codebase-cleanup

Technical debt reduction, dependency updates, and code refactoring automation

## Components

### Agents

- **code-reviewer**: See `agents/code-reviewer.md`
- **test-automator**: See `agents/test-automator.md`

### Commands

- **/codebase-cleanup:deps-audit**: See `commands/deps-audit.md`
- **/codebase-cleanup:refactor-clean**: See `commands/refactor-clean.md`
- **/codebase-cleanup:tech-debt**: See `commands/tech-debt.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
