# tdd-workflows

Test-driven development methodology with red-green-refactor cycles and code review

## Components

### Agents

- **code-reviewer**: See `agents/code-reviewer.md`
- **tdd-orchestrator**: See `agents/tdd-orchestrator.md`

### Commands

- **/tdd-workflows:tdd-cycle**: See `commands/tdd-cycle.md`
- **/tdd-workflows:tdd-green**: See `commands/tdd-green.md`
- **/tdd-workflows:tdd-red**: See `commands/tdd-red.md`
- **/tdd-workflows:tdd-refactor**: See `commands/tdd-refactor.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
