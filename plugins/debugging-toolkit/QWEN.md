# debugging-toolkit

Interactive debugging, developer experience optimization, and smart debugging workflows

## Components

### Agents

- **debugger**: See `agents/debugger.md`
- **dx-optimizer**: See `agents/dx-optimizer.md`

### Commands

- **/debugging-toolkit:smart-debug**: See `commands/smart-debug.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
