# distributed-debugging

Distributed system tracing and debugging across microservices

## Components

### Agents

- **devops-troubleshooter**: See `agents/devops-troubleshooter.md`
- **error-detective**: See `agents/error-detective.md`

### Commands

- **/distributed-debugging:debug-trace**: See `commands/debug-trace.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
