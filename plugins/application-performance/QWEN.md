# application-performance

Application profiling, performance optimization, and observability for frontend and backend systems

## Components

### Agents

- **frontend-developer**: See `agents/frontend-developer.md`
- **observability-engineer**: See `agents/observability-engineer.md`
- **performance-engineer**: See `agents/performance-engineer.md`

### Commands

- **/application-performance:performance-optimization**: See `commands/performance-optimization.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
