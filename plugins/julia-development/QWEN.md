# julia-development

Modern Julia development with Julia 1.10+, package management, scientific computing, high-performance numerical code, and production best practices

## Components

### Agents

- **julia-pro**: See `agents/julia-pro.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
