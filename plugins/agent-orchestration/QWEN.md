# agent-orchestration

Multi-agent system optimization, agent improvement workflows, and context management

## Components

### Agents

- **context-manager**: See `agents/context-manager.md`

### Commands

- **/agent-orchestration:improve-agent**: See `commands/improve-agent.md`
- **/agent-orchestration:multi-agent-optimize**: See `commands/multi-agent-optimize.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
