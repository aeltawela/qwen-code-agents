# git-pr-workflows

Git workflow automation, pull request enhancement, and team onboarding processes

## Components

### Agents

- **code-reviewer**: See `agents/code-reviewer.md`

### Commands

- **/git-pr-workflows:git-workflow**: See `commands/git-workflow.md`
- **/git-pr-workflows:onboard**: See `commands/onboard.md`
- **/git-pr-workflows:pr-enhance**: See `commands/pr-enhance.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
