# full-stack-orchestration

End-to-end feature orchestration with testing, security, performance, and deployment

## Components

### Agents

- **deployment-engineer**: See `agents/deployment-engineer.md`
- **performance-engineer**: See `agents/performance-engineer.md`
- **security-auditor**: See `agents/security-auditor.md`
- **test-automator**: See `agents/test-automator.md`

### Commands

- **/full-stack-orchestration:full-stack-feature**: See `commands/full-stack-feature.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
