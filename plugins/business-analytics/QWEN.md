# business-analytics

Business metrics analysis, KPI tracking, financial reporting, and data-driven decision making

## Components

### Agents

- **business-analyst**: See `agents/business-analyst.md`

### Skills

- **data-storytelling**: See `skills/data-storytelling/SKILL.md`
- **kpi-dashboard-design**: See `skills/kpi-dashboard-design/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
