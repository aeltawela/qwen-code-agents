# frontend-mobile-security

XSS prevention, CSRF protection, content security policies, mobile app security, and secure storage patterns

## Components

### Agents

- **frontend-developer**: See `agents/frontend-developer.md`
- **frontend-security-coder**: See `agents/frontend-security-coder.md`
- **mobile-security-coder**: See `agents/mobile-security-coder.md`

### Commands

- **/frontend-mobile-security:xss-scan**: See `commands/xss-scan.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
