# customer-sales-automation

Customer support workflow automation, sales pipeline management, email campaigns, and CRM integration

## Components

### Agents

- **customer-support**: See `agents/customer-support.md`
- **sales-automator**: See `agents/sales-automator.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
