# systems-programming

Systems programming with Rust, Go, C, and C++ for performance-critical and low-level development

## Components

### Agents

- **c-pro**: See `agents/c-pro.md`
- **cpp-pro**: See `agents/cpp-pro.md`
- **golang-pro**: See `agents/golang-pro.md`
- **rust-pro**: See `agents/rust-pro.md`

### Commands

- **/systems-programming:rust-project**: See `commands/rust-project.md`

### Skills

- **go-concurrency-patterns**: See `skills/go-concurrency-patterns/SKILL.md`
- **memory-safety-patterns**: See `skills/memory-safety-patterns/SKILL.md`
- **rust-async-patterns**: See `skills/rust-async-patterns/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
