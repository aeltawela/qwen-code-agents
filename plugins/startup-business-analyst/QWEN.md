# startup-business-analyst

Comprehensive startup business analysis with market sizing (TAM/SAM/SOM), financial modeling, team planning, and strategic research

## Components

### Agents

- **startup-analyst**: See `agents/startup-analyst.md`

### Commands

- **/startup-business-analyst:business-case**: See `commands/business-case.md`
- **/startup-business-analyst:financial-projections**: See `commands/financial-projections.md`
- **/startup-business-analyst:market-opportunity**: See `commands/market-opportunity.md`

### Skills

- **competitive-landscape**: See `skills/competitive-landscape/SKILL.md`
- **market-sizing-analysis**: See `skills/market-sizing-analysis/SKILL.md`
- **startup-financial-modeling**: See `skills/startup-financial-modeling/SKILL.md`
- **startup-metrics-framework**: See `skills/startup-metrics-framework/SKILL.md`
- **team-composition-analysis**: See `skills/team-composition-analysis/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
