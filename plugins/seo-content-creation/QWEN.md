# seo-content-creation

SEO content writing, planning, and quality auditing with E-E-A-T optimization

## Components

### Agents

- **seo-content-auditor**: See `agents/seo-content-auditor.md`
- **seo-content-planner**: See `agents/seo-content-planner.md`
- **seo-content-writer**: See `agents/seo-content-writer.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
