# block-no-verify

PreToolUse hook that prevents AI agents from using --no-verify, --no-gpg-sign, and other bypass flags that skip git hooks

## Components

### Commands

- **/block-no-verify:block-no-verify**: See `commands/block-no-verify.md`

### Skills

- **block-no-verify-hook**: See `skills/block-no-verify-hook/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
