# content-marketing

Content marketing strategy, web research, and information synthesis for marketing operations

## Components

### Agents

- **content-marketer**: See `agents/content-marketer.md`
- **search-specialist**: See `agents/search-specialist.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
