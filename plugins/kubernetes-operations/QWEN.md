Kubernetes manifest generation, networking configuration, security policies, observability setup, GitOps workflows, and auto-scaling

### Skills

- **k8s-security-policies**: See `skills/k8s-security-policies/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
