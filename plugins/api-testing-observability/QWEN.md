# api-testing-observability

API testing automation, request mocking, OpenAPI documentation generation, observability setup, and monitoring

## Components

### Agents

- **api-documenter**: See `agents/api-documenter.md`

### Commands

- **/api-testing-observability:api-mock**: See `commands/api-mock.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
