# dependency-management

Dependency auditing, version management, and security vulnerability scanning

## Components

### Agents

- **legacy-modernizer**: See `agents/legacy-modernizer.md`

### Commands

- **/dependency-management:deps-audit**: See `commands/deps-audit.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
