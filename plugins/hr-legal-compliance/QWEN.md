# hr-legal-compliance

HR policy documentation, legal compliance templates (GDPR/SOC2/HIPAA), employment contracts, and regulatory documentation

## Components

### Agents

- **hr-pro**: See `agents/hr-pro.md`
- **legal-advisor**: See `agents/legal-advisor.md`

### Skills

- **employment-contract-templates**: See `skills/employment-contract-templates/SKILL.md`
- **gdpr-data-handling**: See `skills/gdpr-data-handling/SKILL.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
