# web-scripting

Web scripting with PHP and Ruby for web applications, CMS development, and backend services

## Components

### Agents

- **php-pro**: See `agents/php-pro.md`
- **ruby-pro**: See `agents/ruby-pro.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
