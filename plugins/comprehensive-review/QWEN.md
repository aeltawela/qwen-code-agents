# comprehensive-review

Multi-perspective code analysis covering architecture, security, and best practices

## Components

### Agents

- **architect-review**: See `agents/architect-review.md`
- **code-reviewer**: See `agents/code-reviewer.md`
- **security-auditor**: See `agents/security-auditor.md`

### Commands

- **/comprehensive-review:full-review**: See `commands/full-review.md`
- **/comprehensive-review:pr-enhance**: See `commands/pr-enhance.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
