# unit-testing

Unit and integration test automation for Python and JavaScript with debugging support

## Components

### Agents

- **debugger**: See `agents/debugger.md`
- **test-automator**: See `agents/test-automator.md`

### Commands

- **/unit-testing:test-generate**: See `commands/test-generate.md`

## Usage

This extension is designed for Qwen Code. Install it with:

```
qwen extensions install <path-to-this-directory>
```

Or copy to `~/.qwen/extensions/` for global availability.
